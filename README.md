# i150N 🌐

**i150N** is a community-driven translation project for **SakuraLands**, supporting **148 languages**.

## Getting Started

1. Fork or clone this repository
2. Create a branch for your changes
3. Make your translations or improvements
4. Submit a Pull Request if you want your changes reviewed or merged

## Supported Languages

This project supports **148 languages** for the server's in-game messages and interface.

### Legacy / Removed Languages

Two legacy languages are no longer supported on the server:

| # | In-Game                 | English                | Language Code | Reason              |
| - | ----------------------- | ---------------------- | ------------- | ------------------- |
| 1 | Español (Latinoamérica) | Latin American Spanish | es_419        | Removed, deprecated |
| 2 | Norsk (Bokmål)          | Norwegian              | nb_NO         | Removed, deprecated |
